# TG 计划模式要求

1. 在本项目中创建计划，必须拆分两个文件`tg-xx-plan.md`和`tg-xx-tasks.md`
2. `plan`文件中维护计划大纲
3. `tasks`维护具体事项的形式，示例：
- ☐ xxxxxx
- ☑ xxxxxx

计划全部完成，请在文件名上标记勾选符号`✓`，示例：
- `✓tg-xx-plan.md`
- `✓tg-xx-tasks.md`
